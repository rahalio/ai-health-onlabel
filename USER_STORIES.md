# Onlabel — User stories

**Product:** [PRODUCT.md](./PRODUCT.md)


### Specialty sales representative

- As a specialty rep, I want my daily action list to contain only actions I can execute today, so that I never find out in the room that my detail aid expired last week.
- As a specialty rep, I want the approved claim set and its references attached to each suggested message, so that I can answer a clinical question without improvising off-label.
- As a specialty rep, I want to capture a meal or material spend as part of closing the call, so that disclosure is not reconstructed from my expense report three weeks later.
- As a specialty rep, I want a named reason when an action is withheld, so that I can tell a system fault apart from a genuine restriction and know who will unblock it. *(exception path)*

### Medical science liaison

- As a medical science liaison, I want my scientific exchange records kept out of commercial targeting, so that answering an unsolicited request can never be turned into a sales signal.
- As an MSL, I want unsolicited information requests tracked with their fulfilment and reference set, so that my response is defensible as scientific exchange rather than promotion.
- As an MSL, I want to see which accounts commercial is engaging without seeing their promotional plan, so that we avoid collisions without breaching the wall.

### Medical, legal and regulatory reviewer

- As a regulatory reviewer, I want review triggered only where a proposed message genuinely differs from an approved claim, so that ten launches do not mean ten times my queue.
- As a regulatory reviewer, I want a new label version to automatically withdraw every affected asset and queued action in that market, so that withdrawal is not a manual sweep I might miss. *(exception path)*
- As a legal reviewer, I want every approved asset to carry an expiry and a claim-to-reference mapping, so that an audit question resolves in minutes rather than a week.

### Market access and payer account director

- As a payer account director, I want payer engagements to run on economic evidence and value dossiers under their own approval path, so that a health-system conversation is never fed promotional claims.
- As a payer account director, I want my engagement measured against the health-system metric we committed to move, so that value is judged on cost per episode or length of stay rather than meeting count.

### Compliance monitoring and transparency

- As a compliance monitoring officer, I want the targeting rationale for any suggested action stated in business terms, so that I can answer a monitor without a data science translation layer. *(governance path)*
- As a compliance officer, I want any attempt to use patient support programme data for commercial targeting blocked and logged as a control event, so that the wall is demonstrable rather than declared. *(governance path)*
- As a transparency analyst, I want captured transfers of value to reconcile per jurisdiction to the statutory submission without rework, so that disclosure season is a report run rather than a project.
